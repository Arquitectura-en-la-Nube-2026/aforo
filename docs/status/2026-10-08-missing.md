## Open questions for the owners

- **Inventory confirm after the deadline.** The contract says confirm only checks
  `status = ACTIVE`. A payment approved after `expires_at` but before the expiry task or sweep
  runs is still confirmed. Tighten it (a contract change), or accept it?
- **Orders replay byte order.** Orders stores idempotent responses as `jsonb`, so a replay has
  the same content but a different key order. Inventory uses `json` and is byte-identical. Align?
- **Pass verification (D-07 / RD-04).** The plan suggested bringing it back if Milestone 2 landed
  on time. It did not: keep it out of scope.
