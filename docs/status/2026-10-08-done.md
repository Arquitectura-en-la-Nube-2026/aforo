## Bugs found and fixed on Oct 8

- **Orders did not boot in its image** (`#38`): it asked for `class-validator@^0.15` while gateway
  asked for `^0.14`; npm hoisted gateway's copy, nested orders', and `@nestjs/common` (hoisted)
  could not see the nested one in an image that installs only orders. Locally every test passed.
- **Every payment webhook became a 500 at the gateway** (`#39`): orders answers with an empty 200
  labeled `text/html`; the gateway treated any non-JSON answer as foreign. The payment still went
  through, but Cloud Tasks retried each notification five times.
- **The first queue join after a pause failed** (`#40`): the queue scales to zero, a cold start
  took ~3.2 s and the gateway gave up at 2.5 s.
- **A flaky queue test** failed `main` once (`#33`).
- **`make apply` creates a new gateway/queue/web revision** with the same image every time (the
  revision name is reset). Harmless, but a deploy is still needed to pick up new code.

## Decisions taken

- **ADR-0007 accepted** (Oct 7): the web is Next.js.
- **Platform took over** catalog (owner Juan José, no code on any branch), inventory and finishing
  orders, because the owners were not responsive.
- **Catalog behavior the contract left open** (catalog README): publishing an already published
  event is a 200 that emits nothing; a list without `status` includes drafts; no organizer roles.
- **Seed dates are fixed**, not relative to the run, so the prewarmer skips all three events and
  the seed never raises min instances.
- **Timeouts above the 2.5 s convention**, documented in the gateway README: orders 15 s (it waits
  for its own E-06 retries), mock pages 10 s, queue 8 s (cold start).
- **Always open the web at** `https://aforo-web-68220265740.southamerica-east1.run.app` (CORS).
